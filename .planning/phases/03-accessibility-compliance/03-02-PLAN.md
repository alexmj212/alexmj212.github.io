Step 2: Enhance PortfolioDialog component in src/components/portfoilo/Portfolio.tsx

The current PortfolioDialog is missing critical accessibility features. Apply these changes:

A) Add imports at top of file:
```tsx
import { FocusTrap } from 'focus-trap-react'
```

B) Add refs to PortfolioDialog for focus management:
- Add `closeButtonRef = React.useRef<HTMLButtonElement>(null)`
- Add `triggerRef = React.useRef<HTMLElement | null>(null)` (store the element that opened the dialog)

C) Update the isOpen useEffect to manage focus:
- When opening: Store `document.activeElement` in triggerRef, call showModal(), then focus closeButtonRef after a setTimeout(0)
- When closing: Call close(), then restore focus with `triggerRef.current?.focus()`

D) Add ARIA attributes to dialog element:
```tsx
<dialog
  ref={dialogRef}
  role="dialog"
  aria-modal="true"
  aria-labelledby="portfolio-dialog-title"
  className="...existing classes..."
>
```

E) Add id to the h2 title in dialog:
```tsx
<h2 id="portfolio-dialog-title" className="content-h2">{item.project}</h2>
```

F) Also fix heading hierarchy in dialog: Change h4 elements (Challenge, Solution, Impact, Technical Highlights) to h3. The dialog title is h2, so subsections should be h3. Keep the existing CSS classes (subsection-header, gradient-border-left).

G) Add aria-label to close button:
```tsx
<button
  ref={closeButtonRef}
  className="...existing classes..."
  onClick={onClose}
  aria-label="Close dialog"
>
```

H) Add screen reader text for external links in dialog footer:
```tsx
<a href={item.link} target="_blank" rel="noopener noreferrer" className="...">
  Visit Project
  <span className="sr-only"> (opens in new window)</span>
  <i className="fas fa-external-link-alt ml-2" aria-hidden="true"></i>
</a>
```

I) Wrap the dialog content with FocusTrap:
```tsx
<FocusTrap
  active={isOpen}
  focusTrapOptions={{
    initialFocus: false,
    escapeDeactivates: false,
    clickOutsideDeactivates: false,
    allowOutsideClick: true,
    returnFocusOnDeactivate: false,
  }}
>
  <dialog ...>
    ...existing dialog content...
  </dialog>
</FocusTrap>
```

IMPORTANT: Set `escapeDeactivates: false` and `returnFocusOnDeactivate: false` because the existing handleEscapeKey and close logic already handle Escape and focus restoration. We don't want focus-trap to conflict. Set `initialFocus: false` because we manually focus the close button in the useEffect. Set `clickOutsideDeactivates: false` because backdrop click is handled by existing handleBackdropClick.

J) Fix the Portfolio cards section heading: Change h1 "Portfolio" to h2 (matching the pattern from Plan 01). This is inside the Portfolio component's render, not the dialog.

K) Make portfolio cards keyboard-accessible: Currently cards use onClick only. Add:
```tsx
<article
  key={...}
  className="portfolio-card"
  data-project={index + 1}
  onClick={() => openDialog(portfolioItem)}
  onKeyDown={(e) => {
    if (e.key === 'Enter' || e.key === ' ') {
      e.preventDefault()
      openDialog(portfolioItem)
    }
  }}
  tabIndex={0}
  role="button"
  aria-label={`View ${portfolioItem.project} project details`}
>
```

L) Also add sr-only text and aria-hidden to external link icons on portfolio cards:
```tsx
<a href={portfolioItem.link} ...>
  Visit Project
  <span className="sr-only"> (opens in new window)</span>
  <i className="fas fa-external-link-alt ml-2" aria-hidden="true"></i>
</a>
```
