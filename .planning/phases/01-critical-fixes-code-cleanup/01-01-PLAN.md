<objective>
Fix Three.js memory leaks by implementing comprehensive GPU resource cleanup.

Purpose: Three.js creates GPU resources (geometries, materials, renderer) that JavaScript's garbage collector cannot free. Without explicit disposal, these leak memory on every route navigation. This is the highest priority fix blocking production stability.

Output: ThreeBackground.tsx with proper useEffect cleanup that disposes all GPU resources, cancels animation frames, and removes event listeners.
</objective>

<task type="auto">
  <name>Task 1: Consolidate useEffect hooks and implement comprehensive cleanup</name>
  <files>src/components/ThreeBackground.tsx</files>
  <action>
The current component has two separate useEffect hooks - one for initialization and one for cleanup. This is fragmented and the cleanup is incomplete.

Consolidate into a single useEffect:
1. Move all initialization code into one useEffect
2. Track ALL created resources for disposal:
   - Store scene, camera, renderer in refs or local variables accessible to cleanup
   - Track the particleGeometry (shared geometry)
   - Track all materials (original + cloned for each particle)
   - Track trailGroup and its children

3. In the cleanup function, follow this EXACT order:
   a. Cancel animation frame FIRST: `cancelAnimationFrame(animationIdRef.current)`
   b. Remove resize event listener: `window.removeEventListener('resize', handleResize)`
   c. Traverse scene and dispose ALL meshes and lines:
      ```typescript
      scene.traverse((object) => {
        if (object instanceof THREE.Mesh) {
          object.geometry?.dispose();
          if (Array.isArray(object.material)) {
            object.material.forEach(m => m.dispose());
          } else if (object.material) {
            (object.material as THREE.Material).dispose();
          }
        }
        if (object instanceof THREE.Line) {
          object.geometry?.dispose();
          if (object.material instanceof THREE.Material) {
            object.material.dispose();
          }
        }
      });
      ```
   d. Clear the scene: `scene.clear()`
   e. Dispose the renderer LAST: `renderer.dispose()`
   f. Nullify refs: `rendererRef.current = null`

4. Remove the separate cleanup useEffect (lines 341-350) - merge into main hook

Do NOT change:
- Animation logic or visual appearance
- CONFIG values or camera setup
- The JSX structure

WHY this order matters: Disposing renderer before scene cleanup can cause WebGL errors. Animation must stop before disposing or we'll render with disposed resources.
