Current behavior: `onError={(e) => { e.currentTarget.style.display = 'none'; }}` hides broken images, leaving empty space.

Replace with state-based fallback that shows a placeholder with clear messaging.

1. Add state to PortfolioDialog component (inside the component, after dialogRef):
```typescript
const [dialogImageError, setDialogImageError] = useState(false);

// Reset image error state when item changes
React.useEffect(() => {
  setDialogImageError(false);
}, [item]);
```

2. Update the image in PortfolioDialog (around line 80-90):
```tsx
{item.images && item.images.length > 0 && (
  <div className="w-full lg:w-80 h-48 lg:h-64 flex-shrink-0 rounded-lg overflow-hidden bg-gray-100 dark:bg-gray-800">
    {!dialogImageError ? (
      <img
        src={item.images[0]}
        alt={item.project}
        className="w-full h-full object-contain"
        onError={() => setDialogImageError(true)}
      />
    ) : (
      <div className="w-full h-full flex flex-col items-center justify-center text-gray-400 dark:text-gray-500">
        <span className="text-4xl mb-2">📷</span>
        <p className="text-sm">Image not available</p>
      </div>
    )}
  </div>
)}
```

3. For the portfolio cards, create a small wrapper component or use index-based state. Since cards are mapped, use a separate ImageWithFallback approach:

Add before the Portfolio component (after PortfolioDialog):
```tsx
const PortfolioImage: React.FC<{ src: string; alt: string }> = ({ src, alt }) => {
  const [hasError, setHasError] = useState(false);

  if (hasError) {
    return (
      <div className="w-full h-full flex flex-col items-center justify-center text-gray-400 dark:text-gray-500 bg-gray-100 dark:bg-gray-800">
        <span className="text-3xl mb-1">📷</span>
        <p className="text-xs">Image not available</p>
      </div>
    );
  }

  return (
    <img
      src={src}
      alt={alt}
      onError={() => setHasError(true)}
    />
  );
};
```
