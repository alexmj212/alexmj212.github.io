<task type="auto">
  <name>Task 1: Implement comprehensive memory disposal targeting identified leak sources</name>
  <files>src/components/ThreeBackground.tsx</files>
  <action>
    Analyze the current cleanup implementation and fix these specific leak sources:

    **1. Cloned materials not tracked (Line 239):**
    - Current: `particleMaterial.clone()` creates new material per particle but only base material is stored
    - Fix: Track cloned materials in array and dispose each during cleanup
    - Add: `const clonedMaterials: THREE.Material[] = [];` and push each clone
    - In cleanup: iterate clonedMaterials and call .dispose() on each

    **2. Particles array retains references:**
    - Current: `const particles: any[] = [];` holds mesh references in closure
    - Fix: Clear the array explicitly during cleanup before scene.traverse
    - Add: `particles.length = 0;` or `particles.splice(0, particles.length);`

    **3. Missing WebGL context cleanup:**
    - Current: `renderer.dispose()` is called but WebGL context may retain GPU memory
    - Fix: Add `renderer.forceContextLoss()` AFTER renderer.dispose()
    - Add: `renderer.domElement.remove()` to detach canvas from DOM tree

    **4. Shared geometry disposed but may retain:**
    - Current: particleGeometry is shared across all particles
    - Fix: Ensure it's disposed BEFORE scene.traverse (dispose clones first, then shared)
    - Add explicit: `particleGeometry.dispose();` in cleanup before traverse

    **5. Base material not disposed:**
    - Current: particleMaterial (base material) is created but only clones are used
    - Fix: Add explicit `particleMaterial.dispose();` in cleanup

    **6. Refs cleanup incomplete:**
    - Current: Only rendererRef.current is nullified
    - Fix: Also set `animationIdRef.current = undefined;`

    **7. Move shared resources to refs for cleanup access:**
    - Current: particleGeometry, particleMaterial, particles array are local variables
    - Fix: Store references accessible from cleanup function OR move disposal before scene.traverse

    **Implementation approach:**
    1. Add tracking array for cloned materials (after particleMaterial creation)
    2. Push each cloned material when creating particles (line 239)
    3. In cleanup function, add this order:
       a. Cancel animation frame (already exists)
       b. Remove event listener (already exists)
       c. Dispose all cloned materials
       d. Dispose base particleMaterial
       e. Dispose shared particleGeometry
       f. Clear particles array
       g. Scene traverse and dispose (already exists, but now redundant for particles)
       h. Scene clear (already exists)
       i. Renderer dispose (already exists)
       j. Force context loss
       k. Remove canvas from DOM
       l. Nullify all refs

    **Do NOT:**
    - Remove existing cleanup code unless redundant
    - Break the animation loop functionality
    - Remove development logging (keep it for verification)
  </action>
