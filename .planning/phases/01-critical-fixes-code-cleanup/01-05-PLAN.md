  <how-to-verify>
**Chrome DevTools Memory Verification:**

1. **Preparation:**
   - Run `pnpm dev` to start development server
   - Open Chrome and navigate to http://localhost:3000
   - Open DevTools (F12) → Memory tab
   - Select "Heap snapshot" profiling type

2. **Take BASELINE snapshot:**
   - Click "Take snapshot" button
   - Name it "BASELINE" (click on "Snapshot 1" to rename)
   - Record the total size

3. **Perform mount/unmount cycles:**
   - Navigate to a different route (if using react-router) OR
   - Close the browser tab and reopen OR
   - Force unmount by conditionally rendering ThreeBackground

   For this app (SPA without route changes for Three.js):
   - Scroll down past the hero section (Three.js stays mounted)
   - Open portfolio dialog, close it (tests dialog cleanup)
   - Repeat dialog open/close 5 times
   - Refresh the page 5 times (each refresh = full unmount/remount cycle)

4. **Force garbage collection:**
   - Click the trash can icon (🗑️) in DevTools Memory tab
   - This forces immediate garbage collection

5. **Take COMPARISON snapshot:**
   - Click "Take snapshot" again
   - Name it "COMPARISON"

6. **Analyze results:**
   - Select COMPARISON snapshot
   - Change view to "Comparison" (dropdown near top)
   - Select BASELINE as comparison target
   - Look for:
     - THREE.Mesh / THREE.Scene / THREE.Geometry retained? (should be 0)
     - Detached HTMLElement nodes? (should be 0 or minimal)
     - Large retained size delta? (should be < 1MB)

7. **Document findings:**
   Create file at `.planning/phases/01-critical-fixes-code-cleanup/MEMORY-VERIFICATION.md`:

   ```markdown
   # Memory Verification Results

   **Date:** [today's date]
   **Browser:** Chrome [version]
   **Test scenario:** 5 page refresh cycles + 5 dialog open/close cycles

   ## Heap Snapshot Comparison

   | Metric | BASELINE | COMPARISON | Delta |
   |--------|----------|------------|-------|
   | Total size | X MB | Y MB | ±Z MB |
   | JS Heap | X MB | Y MB | ±Z MB |

   ## Retained Objects Check

   - THREE.Mesh instances: [count - should be 0 after cleanup]
   - THREE.Scene instances: [count - should be 0]
   - THREE.Geometry instances: [count - should be 0]
   - Detached DOM nodes: [count - should be 0]

   ## Result

   [PASS/FAIL] - [explanation]

   ## Notes

   [Any observations about memory behavior]
   ```

8. **Success criteria:**
   - Retained size delta < 1MB after 5 cycles
   - No THREE.js objects in Comparison view
   - No significant detached DOM node growth
  </how-to-verify>
