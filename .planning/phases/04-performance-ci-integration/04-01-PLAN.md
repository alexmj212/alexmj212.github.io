<task type="auto">
  <name>Task 2: Throttle Navbar scroll handler and create performance budget</name>
  <files>src/components/Navbar.tsx, budget.json</files>
  <action>
    1. Throttle Navbar scroll handler in `src/components/Navbar.tsx`:
       - Add a `useRef` for throttle tracking: `const throttleTimer = useRef<ReturnType<typeof setTimeout> | null>(null)`
       - In the existing `handleScroll` function wrapper, implement throttling:
         - If `throttleTimer.current` is set, return early (skip this scroll event)
         - Otherwise, execute the scroll logic immediately
         - Set `throttleTimer.current = setTimeout(() => { throttleTimer.current = null }, 100)` (100ms throttle)
       - Clean up timer in the useEffect return: `if (throttleTimer.current) clearTimeout(throttleTimer.current)`
       - Do NOT add lodash or any external throttle library - inline implementation is sufficient for one handler
       - Keep the existing scroll logic (threshold check, direction detection) unchanged

    2. Create `budget.json` at project root:
       ```json
       [
         {
           "path": "/*",
           "timings": [
             { "metric": "interactive", "budget": 5000 },
             { "metric": "first-contentful-paint", "budget": 2000 }
           ],
           "resourceSizes": [
             { "resourceType": "script", "budget": 150 },
             { "resourceType": "image", "budget": 500 },
             { "resourceType": "total", "budget": 1000 }
           ],
           "resourceCounts": [
             { "resourceType": "third-party", "budget": 10 }
           ]
         }
       ]
       ```
       Budget values are generous starting points (from RESEARCH.md recommendations). Will be tightened based on Lighthouse CI data.
  </action>

    - All existing tests pass: `npx vitest run`
  </verify>
